# Tenant Distribution Exclusions

The following root-level files are intentionally retained in the controlled reconstruction workspace and pre-P0 source snapshot, but excluded from the Tenant distribution archive:

| File | Reason |
|---|---|
| `check_latest.php` | Ad-hoc script that mutates an exam score to `FINALIZED`. |
| `debug_auth.php` | Debug script reads demo identity and exam data using tenant-bypassing query scope removal. |
| `debug_scores.php` | Debug output exposes question snapshot metadata and score details. |
| `phase6f_seed.php` | Ad-hoc cross-tenant/demo seeder with static demo password and role creation. |
| `read_attempts.php` | Ad-hoc reader enumerates users across a tenant using `withoutGlobalScopes()`. |
| `smoke_test.php` | Hard-coded demo credentials and token, performs API workflow, and raises `attempt_limit_override` to 99. |
| `tenant_id}` | Empty, zero-byte artefact present in historical source snapshot; not application source. |
| `database/seeders/DemoDataSeeder.php` | Development/demo-only seeder contains static demo credentials; retained in workspace for isolated tests but excluded from the distribution package. |
| `database/seeders/RuntimeTestSeeder.php` | Runtime fixture seeder assumes pre-created demo identities and mutates exam/question data; excluded from Tenant distribution. |
| `.phpunit.result.cache` | Generated local PHPUnit cache; excluded. |
| `phpunit.mysql.xml` | Test-only MySQL config contains `force=true` and disposable DB assumptions; excluded to prevent accidental execution against a non-disposable database. |
| `storage/framework/sessions/*` | Runtime session state; excluded. |
| `storage/framework/views/*` | Compiled Blade output; regenerated at runtime. |
| `storage/framework/cache/*` | Runtime cache; regenerated at runtime. |
| `storage/reports/*` | Local test/benchmark output; excluded from deployment package. |
| `bootstrap/cache/*` (except `.gitignore`) | Generated framework manifests/config cache; regenerated by the deployment process. |
| `tenant_id}` | Empty artefact; excluded.

The six PHP files are not deleted from the controlled source workspace. They are excluded from the distributable Tenant ZIP only. The empty `tenant_id}` artefact is also excluded. Runtime test fixtures under `tests/` remain part of source and must use isolated test data only.
